Algorithm

1.start
2.read the choice and operation.
3.if choice is 1,then solve the linear eq.
4.if a!=0,calculate x=-b/a.
5.if a=0,b=o,then infinitely many sol.
6.if a=0,b!=0,then no sol.
7.if choice is 2,then calculate factorial.
8.the value should be between 0 to 12,0!=1.
9.if choice is 3,then solve the quadratic eq.
10.a!=0;if a=0 then it is not a quadratic eq.
11.find roots by using D=b*b-4ac.
12.if D>0,calculate real roots.
13.if D=0,calculate one repeated real root.
14.if D<0,no real root.
15.stop
